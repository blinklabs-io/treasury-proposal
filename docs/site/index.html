Roadmap & Reports

Dingo is Blink Labs' Go implementation of a Cardano node.

This page tracks where the work came from, what exists today and what the treasury-funded roadmap is intended to deliver for DReps, SPOs and developers.

View Dingo on GitHub Read Treasury Proposal

Current Status

  • Syncs from genesis through current Cardano eras.
  • Plutus V1/V2/V3 at 100% conformance.
  • 314 conformance tests passing.
  • ChainSync, mempool, governance transactions, VRF/KES primitives.
  • Preview, Preprod, and Musashi block-production now.
  • Not yet recommended for mainnet block production.

Dingo's Path

Past work built the pieces. Dingo connects them into a Go Cardano node. Future funding takes it from serious implementation to production-grade block producer.

Since 2021

  • Blink Labs builds Cardano infrastructure in Go.
  • gOuroboros mini-protocol foundation.
  • Apollo, Ogmigo, Kugo, and UTxO RPC Go SDK support.

Prior Catalyst + self-funded work

  • Initial Dingo development.
  • Plutigo Plutus evaluator.
  • ouroboros-mock conformance framework.
  • Archive-node storage, proxying, and pruning.
  • Adder indexing/event pipeline.
