# Progress Report - April 2026

Period: April 1, 2026 - April 30, 2026
Report type: Monthly

## Summary

April work maps to the Q2 treasury milestone: testnet block production and the
Leios prototype. The month was focused on the pieces Dingo needs before it can
produce blocks reliably on preview and preprod: consensus correctness,
era-transition behavior, Ouroboros Genesis bootstrap, rollback and fork
recovery, peer governance, monitoring, storage cleanup, and API coverage.

The supporting Go libraries moved with it. gOuroboros supplied protocol and
ledger fixes needed by Dingo. Plutigo focused on evaluator correctness and
performance.

No treasury funds were claimed in April. This report records engineering work
delivered during the month.

Source basis: April 2026 main-branch history in the local Dingo, gOuroboros,
and Plutigo repositories.

## Treasury Milestone

The relevant treasury milestone is Q2: testnet block production and the Leios
prototype. April moved that milestone forward through consensus and operational
work aimed at preview/preprod block production. Delivered work included
pre-Conway forging support, Shelley-to-Allegra VRF correction, leader and nonce
handling, Ouroboros Genesis bootstrap, hard-fork combinator work, era mismatch
handling, peer-governance phases, and safer rollback/fork recovery.

## Dingo

- Shipped 19 April releases from `v0.29.1` through `v0.39.0`.
- Advanced block-production and consensus work: pre-Conway era forging,
  Shelley-to-Allegra VRF behavior, candidate nonce fallback, epoch and leader
  observability, minor protocol version markers in forged blocks, stricter
  Ouroboros security-parameter startup checks, and faster leader-schedule work.
- Improved era-transition behavior: hard-fork combinator shapes, one-step era
  advancement, mid-epoch transition stability signals, structured era mismatch
  errors, era forecast bounds, and safer epoch-boundary handling.
- Added Ouroboros Genesis bootstrap support with Genesis-mode chain selection,
  bootstrap-aware peer promotion, and rollback events.
- Improved rollback, fork, and sync recovery: persistent fork handling, safer
  chain intersects after sparse history or Mithril snapshots, preserved
  blockfetch batches during peer switches, block nonce rollback cleanup, and
  safer local rollback iteration.
- Added operator-facing visibility and controls: Grafana dashboards,
  Prometheus scrape and alert assets, Haskell-style RTS memory metrics, pprof
  listener controls, cleaner Docker contexts, `make test-devnet`, and CI fixes
  for Windows and macOS.
- Expanded the Blockfrost-compatible API surface with pool, address/UTxO,
  metadata-label, epoch/protocol-parameter, asset, block, network, era, and
  genesis endpoints.
- Improved storage and archive behavior with Bark pruning, Bark safety-window
  derivation from ledger state, tunable pruning frequency, SQLite metadata
  batch accumulation, metadata bulk flush support, persistent global settings,
  storage-mode/network safeguards, and block-hash indexing.
- Improved Conway governance handling with ratification, tally, enactment,
  committee quorum persistence, DRep cleanup/replay fixes, and additional
  filtered delegation/reward-account query support.

## gOuroboros

- Shipped April releases `v0.163.5`, `v0.164.0`, `v0.165.0`, `v0.165.1`,
  `v0.165.2`, and `v0.165.3`; Dingo also picked up `gouroboros` `v0.166.0`
  before month end.
- Added Byron-era CBOR transaction/output offset extraction and improved Byron
  block validation errors.
- Added MessageSubmission V2 state-machine support for CIP-0137 and
  end-to-end handshake query mode support.
- Improved consensus and ledger support with higher-precision active-slot
  threshold calculations and safer minimum-fee overflow handling.
- Hardened decode and connection behavior with future-compatible auxiliary data
  decoding, idempotent connection shutdown, Sanchonet bootstrap peer repair,
  and typed era mismatch handling.
- Updated Plutigo and security-sensitive dependencies so Dingo could consume
  current evaluator and protocol-library fixes.

## Plutigo

- Shipped April releases `v0.1.1` through `v0.1.9`.
- Reworked CEK evaluation around a stack-machine path, including
  DeBruijn-specialized no-slippage evaluation, direct forced-builtin fast
  paths, builtin cost caching, lambda/application fast paths, and lower-overhead
  environment lookup.
- Improved CBOR and FLAT decoding with arena-backed paths, retained `big.Int`
  reset handling, arena-backed byte storage, decoder reuse, smaller decode
  chunks, and lazy arena cleanup.
- Added an `ed25519` verification cache and benchmark source directory
  configuration for performance work.
- Fixed CEK cost model handling and constant/list construction issues,
  including broader handling of configurable builtin costs.
- Refreshed toolchain guidance around Go 1.26 and kept nilaway/security
  dependency maintenance moving.
